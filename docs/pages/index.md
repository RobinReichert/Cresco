## What is Cresco?

The name **Cresco** comes from the Latin word crescere — meaning "to grow".
It felt like a natural fit for a project built around nurturing plants
and pushing the boundaries of what open-source hydroponics can be.
Cresco is an open-source smart hydroponics system that takes the guesswork
out of soilless growing. Designed with a focus on clean aesthetics and
intelligent automation, it continuously monitors your growing environment
and keeps everything running at optimal conditions. Built to be extensible
and community-driven, Cresco is for growers who want full control
over their system without sacrificing simplicity or style.

## Getting started

{: #getting-started }

### Installation

To get started, clone the repository:

```bash
git clone https://github.com/RobinReichert/Cresco.git
```

### Quick start

Once cloned, run the setup script from the project root:

```bash
./cresco.sh setup
```

This will set up everything you need to get your Cresco system up and running.
