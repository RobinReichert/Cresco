# Cresco

Cresco is an open-source smart hydroponics system that takes the guesswork out of soilless growing. Designed with a focus on clean aesthetics and intelligent automation, it continuously monitors your growing environment and keeps everything running at optimal conditions. Built to be extensible and community-driven, Cresco is for growers who want full control over their system without sacrificing simplicity or style.

---

## Installation

Clone the repository:

```bash
git clone https://github.com/RobinReichert/Cresco.git
```

## Quick start

Run the setup script from the project root:

```bash
./cresco.sh setup
```
